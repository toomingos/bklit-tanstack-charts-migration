## What the swap actually is

T-D3: any per-index enter-stagger delay formula that reduces to `offset + each * i` (linear in item index `i`) becomes `stagger({each, offset})` (`@tanstack/charts/motion/definition`). Formulas that are not linear in a single item index — window-scaled, random, or dependent on more than one index — stay as hand-written delay functions. `go-to-plan.md` scopes this to "linear only; non-linear keep delay fns."

## What explicitly STAYS custom

Everything in the "stays custom" rows of the table above, plus: whatever scalar computation feeds `each`/`offset` (e.g. `enterStaggerScale`, `animationDuration`, gauge's clamp) is app-level configuration and stays exactly as-is — only the mechanism that turns "item index → delay" changes, not the values feeding it.
