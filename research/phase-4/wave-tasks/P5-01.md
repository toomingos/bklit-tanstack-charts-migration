## Gate

Barrel-only re-exports of already-implemented symbols are **pixel-inert by nature** — nothing here touches a render path, a mark, or an event handler. Do **not** run a `qa/screenshot.mjs` pixel-diff gate for this package; it would burn a QA slot to confirm something a pixel diff structurally cannot detect (a barrel export changes what `import { X } from "@migrated/charts"` resolves to, not what any chart paints).

The real gate, mandatory after **every** sub-run:

1. **`pnpm typecheck` (or `tsc --noEmit`) exit 0** across the full tree, not just the touched files — a barrel is a fan-in point and a bad re-export can break consumers you didn't edit.
2. **A production build, exit 0.** This step exists because tsc's module resolution and the bundler's (Next.js/Turbopack) can diverge on subtle cases — a `export type` vs `export` mismatch, a re-export chain that satisfies tsc's declaration merging but gets elided from the runtime bundle, a case where the wrong file was targeted but still typechecks because a same-named symbol happens to exist there too. The production build is the check that catches "this typechecks but does not actually resolve at runtime."
3. **A resolution spot-check.** The failure mode this package is most exposed to is *an export that typechecks but points at a deleted or wrong module* — TypeScript will usually catch a straightforwardly-missing symbol, but a stale re-export chain, a shadowed name, or a symbol that exists as a type but not as a value can slip through both tsc and a build that doesn't happen to reference it anywhere. Pick a representative sample spanning all three categories (aim for at least 10, including at least one from each sub-run) and force real resolution of each — e.g. temporarily append a throwaway reference block (`const __apiCompatSpotCheck = { SymbolA, SymbolB, ... };`) to an already-tracked file such as `charts/index.ts` itself, confirm it compiles and appears in the build output, then revert that transient edit (reverting an edit is not a deletion — D216 only blocks removing files). Do not leave a permanent unrequested smoke-test file behind.

Run the full three-step gate after TYPES, again after CONSTS, again after HELPER-FNs. A failure in a later sub-run does not necessarily implicate an earlier one, but re-run the full-tree typecheck each time regardless — barrels have wide blast radius.
