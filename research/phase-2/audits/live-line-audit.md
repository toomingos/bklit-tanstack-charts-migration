# LiveLine Audit — migrated/charts/live-line-chart.tsx

## 1. Summary
Migrated LiveLine uses a custom `liveLineMark` bundling `area`+`polyline` per series (`migrated/charts/internal/live-line-mark.ts:22`) inside a single `defineChart` → `<Chart animate:false>` lifecycle, but animation, sizing, hover, and axis chrome are all custom outside the host. The split is ~20% TanStack-native (bundled mark definition + keyed reconcile at ~30fps) vs ~80% custom imperative runtime (continuous rAF lerp loop, synthetic tip points, imperative `LiveHoverChrome`, native pointer refs, SVG overlay). Overall overhead verdict: **very high but architecturally isolated** — the streaming lerp pause-optimization and `hmsTimeFmt`/`pickNiceInterval` paths are verbatim bklit ports, while the rAF+ref hover bypass and 800-line hover chrome duplicate stock TanStack `focus`/`tooltip`/`animate` at measurable maintenance cost.

## 6. Prioritized remediation candidates

1. **Move Y-domain lerp into definition rebuild with `animate` and drop manual rAF** — What to change: remove `nextAnimFrame`/`frameChangePixels`/`animRef` loop and `LIVE_FRAME_COMMIT_MS` throttle; on each `data` tick compute `targetRange` and build `defineChart({ y:{scale:scaleLinear().domain(targetRange).nice()}, animate:{duration:320,easing:bezierEasing}})` and let `reconcileChartSvg` tween `d`/`y` attributes. What it becomes: `defineChart` with `animate:true` per `research/phase-2/tanstack-native/02-render.md` §`runTweens` single RAF, no outer loop. Expected gain: **perf** (one host RAF instead of 60/s raw + 30/s committed; removes per-tick `filter` allocation) + **maint** (streaming per `research/phase-2/tanstack-native/01-load.md` §1.7). Risk: loses asymmetric instant-expand/0.08-contract semantics (bklit-specific). Verification: bench M3b at `window=30` streaming 100 ticks; QA y-axis edge fade at mixed-sign burst.

2. **Wire native pointer focus and remove `cursorXRef` + manual bisector** — What to change: set `defineChart(definition,{focus:'nearest-x', maxFocusDistance:Infinity, tooltip:true})` and move `interpolateAtTime` + `point.series` mapping into `onFocusGroupChange`; delete `pointermove` listener and `bisectTime` per-tick filter+synthetic-push. What it becomes: `onFocusGroupChange=(points)=> chrome.updateHover({point: points[0], series: points})` via host `resolvePointerFocus` (`research/phase-2/tanstack-native/04-interactivity.md` §Focus strategies). Expected gain: **maint** (single hookup, no canvas/inner space dual) + **perf** (host `findNearestPoint` O(n) `least` vs per-tick `filter` O(n) + scale alloc). Risk: host `nearestPoint` Euclidean vs bklit `bisector left` time-only tie-break; must supply custom `ChartFocusStrategy` to preserve strict `left` bisect semantics. Verification: QA hover fractions n=30 window at synthetic branch (two tip points) — synthetic point must not hijack nearest.

3. **Keep `liveLineMark` but add GAP rationale gate** — What to change: add comment bench for `liveLineMark` vs stock `lineY+areaY` at n=500 (heap G4 analogue); if G4 margin shrinks with fewer series, fold back to two stock marks. What it becomes: either justified custom mark (retained with bench note) or two stock marks. Expected gain: **maint** (one fewer custom mark) or confirmed **perf** (retained heap win). Risk: stock `areaY` retains polygon points array that `research/phase-2/inventory/04-migrated-inventory.md` §4 overhead #1 flags as G4-relevant. Verification: bench G4 heap at n=500/1000 with single series vs two.

4. **Consolidate five tip chrome SVG overlay into TanStack `ruleY`+`dot`+`text` marks** — What to change: emit dashed baseline `ruleY`, pulsing dot as second `dot` layer with r channel, badge as `text` mark inside same `defineChart`, and map scrub dim to mark `fillOpacity` channel instead of `registerLiveGroups` imperative writes. What it becomes: all pixels flow through scene→string→DOM, tip chrome reconciled by `reconcileChartSvg` rather than throttled React overlay. Expected gain: **design** (clip/resize/sceneCoord guarantees) + **maint** (no sibling SVG `position:absolute` overlay).
