# Heatmap Audit — Phase 2 Step 0.3

## 1. Summary (2-3 sentences: TanStack-native vs custom split, overall overhead verdict)

`HeatmapCells` (`migrated/charts/internal/heatmap-components.tsx:176`) is TanStack-native — one `defineChart({ marks:[cell(cellData, {x,y,z})], x:{scale:scaleBand}, y:{scale:scaleBand}, color:{scale:scaleOrdinal}, animate:false })` → `<Chart>` — but the outer `HeatmapChart`/`HeatmapChartInner` scaffold (`migrated/charts/heatmap-chart.tsx:81`) is custom: its own `ResizeObserver` sizing gate, functional `(index)=>offset` scales, a 4-state `useHeatmapChartLifecycle` machine, and an imperative `HeatmapHoverCoordinator` + `createPortal` HTML layer replace TanStack's host sizing, `animate`, `focus`/`tooltip`, and `guides`. Overall overhead verdict: **moderate-high** — the `cell` island itself is minimal and correct, but the surrounding calendar math (`heatmap-utils.ts:825` lines), lifecycle, and coordinator/legends (`heatmap-legend.tsx:257`) duplicate work TanStack or shared chart chrome already owns, worth paring where bench fidelity allows.

## 6. Prioritized remediation candidates (numbered, each with: What to change → What it becomes → Expected gain (perf/design/maint) → Risk → Verification via bench/QA gate)

1. **What to change:** Forward sizing to TanStack host — remove outer `ResizeObserver`+`sz` state in `HeatmapChart` and render `HeatmapChartInner` unconditionally with `<Chart width={undefined} aspectRatio={ratio} initialWidth={640}>`, deriving `binWidth/binHeight` from TanStack's `scene.chart` bounds passed into `createMark.render({chart})` instead of `getBoundingClientRect`.
   **What it becomes:** A responsive `defineChart((ctx)=>({ marks:[cell(...)], x:{scale:scaleBand}, y:{scale:scaleBand}, margin }))` definition closing over `ctx.width/height` (`research/phase-2/tanstack-native/01-load.md` §Dynamic `defineChart(config:{chart:(ctx)=>spec})`).
   **Expected gain:** Perf (eliminates mount-time double measure + extra React state; restores SSR `prerender` first-paint — the single largest M1a win per `03-stack-comparison.md` §7 hot-spot 4).
   **Risk:** M — separator `<svg>` positioning must re-derive from `scene` sync, and `computeHeatmapDimensions` calendar math must consume `ctx.width` instead of `sz.w`; snapshot diff risk on fractional widths.
   **Verification:** Bench M1a + SSR HTML snapshot (inner `<svg>` present without JS) + `grep -n ResizeObserver migrated/charts/heatmap-chart.tsx` should be 0; QA screenshot diff for separator alignment.

2. **What to change:** Replace `HeatmapHoverCoordinator` publish-all with TanStack `defineChart(cellData,{ focus: custom Strategy grouping by level || nearest cell, tooltip:{anchor:'point'} })` and keep only a thin React island for `HeatmapTooltip` text via `onFocusChange`/`onFocusGroupChange`.
   **What it becomes:** Imperative `paintFocus` paints the focus ring; `onFocusGroupChange` supplies the single `HeatmapTooltipData` to a memoized tooltip portal; legend cross-highlight becomes `group === hoveredLegendLevel` check driven by the same `ChartPoint.group` value (`research/phase-2/tanstack-native/04-interactivity.md` §Focus strategies `group-x`).
   **Expected gain:** Maint (removes 163-line coordinator + `useSyncExternalStore` fan-out; aligns with `03-stack-comparison.md` Implications rule 1 — removes React hover state from the hot path).
   **Risk:** M — legend cross-highlight (hovering legend dims cells by level) has no direct TanStack built-in; requires a custom `ChartFocusStrategy.group` that treats `count → level` as the grouping key, plus a level-indexed spatial index for 364 cells. Needs pointer-test coverage.
   **Verification:** Pointer-hover bench (tooltip text correctness + dim opacity) + hover no-React-rerender assert (React DevTools highlight) + `grep -n "HeatmapHoverCoordinator" migrated/charts/internal/heatmap-hover-chrome.ts` usage should narrow to 0 for cell dim.

3. **What to change:** Unify `useHeatmapChartLifecycle` into TanStack `animate:{duration: animationDuration, easing:'ease-out'}` + `definition` identity on `revealSignature` (key the `cell` mark's `key` by `revealEpoch` so `reconcileChartSvg` enter tween handles stagger).
   **What it becomes:** `defineChart({ marks, animate:{duration:HEATMAP_DEFAULT_ENTER_DURATION_MS} })` with `key: (d)=>`col:${d.column}-row:${d.row}`` driving `reconcile.ts:138` `addEnterTween` opacity fade (`research/phase-2/tanstack-native/00-README.md` §Animation).
   **Expected gain:** Perf/design (single animation system; 64-sample WAAPI keyframe shim removed; bench M1a settle detection via `reconcile` completion rather than ad-hoc `setTimeout` chain).
   **Risk:** L — current `animateCells=false` branch skips animation entirely (`heatmap-lifecycle.ts:71`); TanStack `respectReducedMotion` already covers it (`renderer.ts:958`).
   **Verification:** Bench `duration=0` and `prefers-reduced-motion` gates + screenshot diff for stagger parity + `grep -n "HEATMAP_LOADING_CONCEAL_MS" migrated/charts/internal/heatmap-lifecycle.ts` should be 0 after adoption.

4. **What to change:** Collapse `HeatmapInteractionProvider`/`Boundary`/`Root` → single `HeatmapInteractionProvider` (or remove it entirely once item 2 lands).
   **What it becomes:** One context value `{ coordinator }` or none; consumers import `useHeatmapInteractionOptional` from the single provider.
   **Expected gain:** Maint (121 lines → ~30; removes `boundary`/`root` props that no demo exercises).
   **Risk:** L.
   **Verification:** No demo regression + `ls migrated/charts/internal/heatmap-interaction.tsx` check that exported `Boundary`/`Root` count drops.

5. **What to change:** Migrate `Children.forEach` + `displayName` separator extraction to `CHART_ROLE` Symbol walk (`heatmap-chart.tsx:404` + `sankey-chart.tsx:145`).
   **What it becomes:** ` (child.type as RoleCarrier)[CHART_ROLE] === "heatmapSeparator"` alongside other charts' extraction (`migrated/charts/children.tsx:24`).
   **Expected gain:** Maint (uniform children contract per `inventory/04-migrated-inventory.md` §children.tsx consolidation).
   **Risk:** L.
   **Verification:** `grep -rn "displayName" migrated/charts` should match only the legacy compatibility shim in `children.tsx` after fix.
