# Choropleth Audit — Phase 2 Step 0.3

## 1. Summary (2-3 sentences: TanStack-native vs custom split, overall overhead verdict)

`geoShape(features, { projection: () => geoMercator().center([0,20]).translate(...).scale(...), fill: resolveFeatureFill })` inside `defineChart({ x:null, y:null, guides:false, margin:0 })` → `<Chart aspectRatio>` is TanStack-native (`migrated/charts/choropleth-chart.tsx:636`), but zoom/pan is a ~190-line manual `ProvidedZoom` matrix reimplementation (`migrated/charts/choropleth-chart.tsx:245`) applied as CSS `transform` on a wrapper div outside TanStack's SVG, hover dim is imperative group-based DOM moves via `data-ts-key` lookup (`migrated/charts/internal/choropleth-hover-chrome.ts:59`), and reveal is dual-timer `800 ms isLoaded + 1100 ms WAAPI` unsynchronized. Overall overhead verdict: **high** — the `geoShape` mark is minimal and correct, while zoom, hover, graticule, and reveal each carry bklit-parity imperative layers that duplicate or bypass TanStack's isomorphic host, focus, and animation paths for modest fidelity gain.

## 6. Prioritized remediation candidates (numbered, each with: What to change → What it becomes → Expected gain (perf/design/maint) → Risk → Verification via bench/QA gate)

1. **What to change:** Replace wrapper-CSS zoom with projection-scale definition swap — remove `createProvidedZoom`/`useZoomState` and have wheel/pinch/drag handlers compute a new `scale`+`translate` tuple fed into `projectionFactory` rebuild → new `defineChart` identity, letting TanStack re-render via `reconcile` with `animate:{duration:180}`.
   **What it becomes:** TanStack `onRender`-adjacent zoom state pattern (`research/phase-2/tanstack-native/04-interactivity.md` §Brush / zoom) — zoom is a prop-driven definition change, not a DOM transform; `applyMatrixToPoint` tooltip correction disappears.
   **Expected gain:** Design (projection and bounds stay in sync — fixes focal-point offset bug) + perf (no extra `ResizeObserver` + wrapper `transform` layer; host `ResizeObserver` suffices) + maint (deletes ~190 lines of matrix math duplicating `@visx/zoom`).
   **Risk:** H — wheel delta `0.95/1.05` and pinch `scaleFactor` ratios must be re-tuned to match bklit feel; rapid pinch may trigger frequent definition rebuilds (debounce or `startTransition` needed).
   **Verification:** Pointer wheel/pinch/drag QA + tooltip centroid still correct after zoom + `grep -n "createProvidedZoom" migrated/charts/choropleth-chart.tsx` should be 0; bench resize still stable.

2. **What to change:** Replace `pathElementsRef` + `featureByTsKey` + `getCentroidForHover` with TanStack `focus` Strategy that emits `ChartPoint` per feature at `geoCentroid`/`projection` anchor, and use `onFocusChange(point)` → `setTooltipData` plus `paintFocus` for focus ring.
   **What it becomes:** `defineChart({ marks:[geoShape(..., { anchor: (f)=>geoCentroid(f) })], focus:'nearest', tooltip:{anchor:'point'} })` with `onFocusChange(point)` bridging to React tooltip portal; dim becomes CSS `opacity` in `onFocusGroupChange` keyed by `point.key` (`research/phase-2/tanstack-native/04-interactivity.md` §Focus strategies, §`paintFocus + paintTooltip`).
   **Expected gain:** Maint (removes ~120 lines of group-wrapper dim logic that fights `reconcile`) + perf (nearest search is `scene.points` linear scan, not DOM `querySelectorAll` per render).
   **Risk:** M — `geoShape` currently emits no `points` for centroid anchoring without explicit `anchor` prop; need to confirm `@tanstack/charts/geo` `GeoShapeOptions.anchor` contract supports custom lon/lat override.
   **Verification:** Hover pointer bench (feature dim + tooltip name/value) + snapshot of `data-ts-key` no longer hard-coded + `grep -n "geo-shape-0:object:null" migrated/charts/choropleth-chart.tsx` should be 0.

3. **What to change:** Unify dual reveal timers under TanStack `animate:{duration:1100, easing:'cubic-bezier(0.85,0,0.15,1)'}` on the `geoShape` definition, removing `isLoaded` `setTimeout` and `data-bkm-revealed` guard; gate interactivity via `onRender` `hasRendered` instead.
   **What it becomes:** One animation system (`reconcileChartSvg` opacity tween) and one readiness flag derived from host `hasRendered`.
   **Expected gain:** Perf (bench settle detection via `reconcile` completion, not `setTimeout` chain) + design (single reveal source of truth).
   **Risk:** L — `animate:false` / `animationDuration=0` fast-path already exists; TanStack `respectReducedMotion` covers reduced-motion.
   **Verification:** Bench M1a settle + `revealSignature` bump re-reveals correctly + `grep -n "data-bkm-revealed" migrated/charts/choropleth-chart.tsx` should be 0.

4. **What to change:** Forward host sizing — initialize `width` via `initialWidth=640` or `Chart` `width`/`initialWidth` prop and render `definition` even when `width===0` (SSR width fallback), measuring graticule/projection from `ctx.width` in a dynamic `defineChart((ctx)=>spec)` instead of `getBoundingClientRect`.
   **What it becomes:** Isomorphic `prerender()` path (`research/phase-2/tanstack-native/01-load.md` §Prerender vs mount vs update) — SSR emits complete `<svg>` with graticule at `initialWidth`.
   **Expected gain:** Perf (M1a first-paint, no flash-of-empty).
   **Risk:** M — graticule `geoPath(projection)` must be sized from `ctx.width` sync with `scene.chart`.
   **Verification:** SSR HTML snapshot contains `<svg>` without JS + `grep -n "ResizeObserver" migrated/charts/choropleth-chart.tsx` narrowed to 0 or host-owned.

5. **What to change:** Extract graticule as an optional `ChoroplethGraticule` custom `createMark` layered in the same `defineChart.marks` array (emit `SceneNode` `path` nodes from `geoGraticule().lines().map(pathGen)`) so it participates in `reconcile` and zoom definition identity.
   **What it becomes:** Native-adjacent composition (no separate `<svg>` overlay, no extra `projection` call).
   **Expected gain:** Perf (one projection path, no overlay) + design (graticule clips to `scene.chart` bounds).
   **Risk:** L — TanStack `scene→string→DOM` already supports custom marks; `geoPath` per line is cheap.
   **Verification:** Screenshot diff for graticule alignment at `step=[10,10]` + `grep -n "ChoroplethGraticuleOverlay" migrated/charts/choropleth-chart.tsx` should be 0 if inlined.
