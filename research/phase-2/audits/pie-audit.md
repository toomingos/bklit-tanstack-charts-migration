# Pie Chart Audit — migrated/charts/pie-chart.tsx

## 1. Summary
TanStack-native `polar()` + `radialArc` scene via `defineChart`/`Chart` carries all SVG production; custom imperative layer owns resize, WAAPI reveal, and hover springs layered on TanStack-rendered DOM via `data-ts-key` queries. Split ≈65% TanStack-native (scene, focusDisabled) / 35% custom (measure, keyframe sampling, spring runtimes). Overall overhead verdict: **moderate, justified** — per-slice React overhead eliminated vs bklit, but 64-sample WAAPI per slice and two WeakMap/cleanup indirections add retained complexity.

## 6. Prioritized remediation candidates
1. **What to change:** Replace index-based `pathEls[i]` mapping with `data-ts-key` lookup. **What it becomes:** `container.querySelector('[data-ts-key="pie-slices:${sliceIndex}"]')` per slice. **Expected gain:** maint — removes fragile order assumption, survives TanStack reorder/filter. **Risk:** low — key format `pie-slices` is TanStack `id` (hardcoded `radialArc` `id: "pie-slices"`), grep-stable. **Verification:** bench `variant-n=4` hover probe + QA pixel diff on reorder; no perf delta.
2. **What to change:** Fix one-shot `bkmRevealed` guard to diff revealed keys (like `reconcileGaugeReveal` `seen` Set). **What it becomes:** `Set<string>` of animated `sliceIndex` keys; only new keys animate on `handleRender`. **Expected gain:** perf/design — grows data incrementally animates only new slices, matches gauge reconciler and bklit `revealEpoch` semantics. **Risk:** low — same pattern already shipped in `gauge-reveal.ts`. **Verification:** bench `data-grow 2→6` WAAPI probe asserts 4 new anims, QA staged screenshot at t=200ms shows sweep on new slices only.
3. **What to change:** Fold `hoverInputsRef` + `enterTransitionRef` into `handleRender`/`useLayoutEffect` dep arrays (use `useCallback` with real deps). **What it becomes:** `handleRender` captures `arcs`, `sliceConfigMap`, `enterTransition` directly; React re-creates callback when they change. **Expected gain:** maint — removes manual ref sync drift. **Risk:** medium — TanStack `onRender` identity check `renderer !== options.renderer` in `renderer.ts:107` destroys surface if `renderSvg` changes; verify `Chart` memo in `Chart.tsx:47` guards. **Verification:** `react-scan` render count + interaction hover still works after `enterTransition` toggle.
4. **What to change:** Remove global `pieCleanupMap` WeakMap; keep cleanup closured in effect. **What it becomes:** Local `Map<Element,()=>void>` inside `useLayoutEffect`, cleared in return. **Expected gain:** maint — single cleanup path, no cross-instance leak. **Risk:** low. **Verification:** mount/unmount 50× loop, assert `getEventListeners` count returns to 0.
5. **What to change:** (Optional) Re-introduce NumberFlow via `CenterStat` shared island if snapshot gate enforces roll. **What it becomes:** Import `migrated/charts/internal/center-stat.tsx` `CenterStat` + `useCenterStatHover` (sanctioned D10 exception used by ring/gauge). **Expected gain:** design — restores bklit double-RAF 0→value roll, pixel-identical. **Risk:** medium — adds `useSyncExternalStore` re-render on hover (scoped to island per `center-stat.tsx` header, not whole chart). **Verification:** Playwright mid-roll screenshot at t=80ms vs bklit-pie bench, `bench/compare` SSIM gate.
