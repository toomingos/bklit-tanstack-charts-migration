# Funnel Chart Audit — migrated/charts/funnel-chart.tsx + internal/funnel-*.ts

## 1. Summary
Disclosed plain-SVG/DIV fallback — no `defineChart`/`Chart` wrapper — reproducing bklit's own `ResizeObserver` measured div + per-stage trapezoid rings (`hSegmentPath`/`vSegmentPath`) and merging bklit's `HSegment/VSegment` + `SegmentLabel` split into one `FunnelSegment` per stage. Reveal and hover are fully imperative (WAAPI per-segment `scale` + `buildProgressKeyframes`, per-ring axis-specific `scaleY`/`scaleX` springs). Split 0% TanStack-native / 100% custom — highest custom share by design. Overall overhead verdict: **moderate, justified** — GAP chart (TanStack has no funnel primitive, see `inventory/03-stack-comparison.md`), but one `ResizeObserver` + N `FunnelSegment` React components + N `FunnelSegmentHoverRuntime` instances scale linearly with stages.

## 6. Prioritized remediation candidates
1. **What to change:** Fix funnel WAAPI `fill:"backwards"` lifecycle vs hover race. **What it becomes:** `anim.onfinish = ()=>{anim.cancel(); el.style.transform="scale(1)" }` pattern like pie/ring, releasing WAAPI so hover spring owns `transform` immediately after reveal. **Expected gain:** design — hover pop no longer stalls when `enterTransition` duration exceeds hover delay. **Risk:** low — same pattern shipped in pie `pathEl` reveal and ring track expand. **Verification:** `staggerDelay=0.3` slow reveal + hover at t=200ms probe, assert ring `scaleY` reaches 1.12 within 260ms, not blocked to reveal end.
2. **What to change:** Make `FunnelSegment` `isHorizontal` branch re-key on orientation change or reset transform origin before WAAPI. **What it becomes:** Key segments as `${stage.label}-${orientation}` so orientation flip remounts, or `useLayoutEffect` synchronously sets `el.style.transformOrigin` before `animate()` schedules. **Expected gain:** design — orientation toggle mid-session (studio) no longer shows wrong-axis origin frame. **Risk:** low — key suffix only, fallback consistent. **Verification:** studio `FunnelChart orientation` select toggle, screenshot before/after orientation change at same `stage.label` set.
3. **What to change:** Guard `key={stage.label}` collision. **What it becomes:** `key={stage.label + "-" + index}` or warn on duplicate labels in dev. **Expected gain:** maint — duplicate label data no longer collapses stages. **Risk:** none — index suffix stable because bklit label set already unique; no reorder penalty beyond bench `__benchUpdate` same-key snap check (snap still works because value-change updates are per-label index, not reorder). **Verification:** render funnel with two stages both `label:"X"` and distinct values, assert 2 segment boxes in DOM, distinct `normStart/End`.
4. **What to change:** Replace `FunnelOrientationContext` with prop drill. **What it becomes:** `FunnelSegment isHorizontal` prop passed directly; remove context provider/consumer. **Expected gain:** maint — removes indirection for a single boolean. **Risk:** none. **Verification:** grep `FunnelOrientationContext` after patch 0 hits, funnel still renders, M1a within noise.
5. **What to change:** Memoize `computeFunnelRings` per segment inputs + reuse for hover `extraScale` lookup. **What it becomes:** `useMemo(()=>computeFunnelRings(layers, scale=>hSegmentPath(...)), [normStart,normEnd,segDim,crossDim,layers,straight,isHorizontal])` per segment; hover runtime reads precomputed `rings.length` consistently. **Expected gain:** perf — avoids recomputing `hSegmentPath` string per layer per render (micro-opt). **Risk:** low. **Verification:** profile `funnel` bench M1a with `layers=5, n=12` before/after, path count identical, no visual change.
