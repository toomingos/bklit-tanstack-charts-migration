# Gate issue ledger

Living ledger of gate findings, one row per stable id. Rows are **classified, not diagnosed**: the category says which behaviour/channel the evidence belongs to, the owner note is for the fix owner. Seeded from the sequential sweep of 2026-09-02 13:41Z (`qa-sweep.sh`, dist 10:27Z) and merged by every `pnpm gate:summary -- --issues` / `pnpm gate:all -- --issues` run since; `status` carries the last run that reproduced the row, and rows that stop reproducing are marked `not reproduced in <run>` rather than deleted.

Id scheme: `qa:<chart>/<n>:<category>` (one row per chart/n and category; the cells column lists every failing or out-of-range cell with its px, history status and mode), `bench:<impl/chart/n>:<metric>`, `bundle:<scenario>`, `checks:<name>`, `census`, `probe:<probe>:<chart>[/<n>][:<impl>]`.

Categories: `hover-dim` (pointer hover dim/highlight parity), `legend` (legend-hover dim cells), `tooltip` (tooltip presence/method mismatch), `axis` (settled-frame drift: ticks, labels, grid — anything that differs before any interaction), `motion/reveal` (depth toggle, loading presets, re-reveal on prop change), `renderer-regime` (D472: charts whose renderer is cardinality-gated at `NATIVE_MOTION_MAX_POINTS = 200` — scatter/composed/line/area/bar/candlestick at n > 200), `brush/zoom`, `polar` (pie/ring/radar/gauge/sunburst family), `harness-race` (D413 straddle cells and any run that produced no report), `bench` (D273 ±20% on M1b/M1c/M3a, console errors, failed invocations), `bundle` (3% pin), `census` (reach-in guard), `checks` (tsc/build/lint).
